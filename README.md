# Word 结构化思考与写作模板集

**让思路有层级，让结构可调整，让想法直接长成文章。**

这套模板最核心的初衷不是“把 Word 排得更漂亮”，而是**用结构化写作辅助思考**。标题层级帮助你把想法分组、命名、排序并建立关系；文档变长以后，Word 的导航窗格会把全文结构持续呈现在眼前，方便检查遗漏、重复、层级和论述顺序。

**模板不会替你思考，但会让思考的结构更容易被看见、检查和重组。** 你可以边写、边整理、边调整，而不必先把完整大纲一次想完。思想结构和最终文稿使用的是同一份 Word 文档，编号、目录、页码、题注和参考文献等功能则尽量减少排版摩擦，把注意力留给内容本身。

> 项目的优先顺序是：**思考 → 结构 → 写作 → 排版。** 详细说明见 [`docs/结构化思考.md`](docs/结构化思考.md)。

**不用配置 Word：下载 → 选模板 → 双击 → 开始写。**

这是一个面向普通 Word 用户的中文结构化写作模板库。你不需要懂 GitHub、VBA、多级列表或 Word 样式设置；成品模板已经预置好标题层级、自动编号、正文样式、长文结构和常用快捷键。

> 支持 Microsoft Word for Windows 与 Microsoft Word for macOS。两个平台分别提供成品模板，以减少字体和快捷键差异带来的问题。

## 直接开始版与常用结构版

每一种编号都有两个起步版本，但不会让新手一开始多做选择：

- **直接开始版（默认）**：只有标题、一级标题和正文，双击就写；
- **带常用结构版（可选）**：在相同编号体系上预置更接近成稿的结构、页码和排版辅助元素。

书籍结构版包含独立书名页、作者占位、前言、自动目录、正文、附录和参考文献；前置部分使用小写罗马页码，正文从阿拉伯数字 `1` 重新开始。一级章标题自动另起新页，并预置镜像页边距、装订线、奇偶页页眉和外侧页码，但不会强制每章必须从奇数页开始。

文章结构版包含作者、单位、日期、摘要、关键词、正文、参考文献以及从第 `1` 页开始的页码。

下载 ZIP 后，直接开始版仍在“书籍模板 / 文章模板”第一层；只有需要现成骨架时才进入 **“带常用结构”** 子文件夹。

## 写长文时已经准备好的能力

模板当前覆盖这些常用场景，但都不是开始写作的前置条件：

- 四级标题自动编号、自动目录与导航窗格；
- 书籍前置部分 / 正文分节、独立页码、奇偶页页眉与双面打印设置；
- Word 原生“图 / 表”题注与交叉引用；
- 书籍图表按一级章编号，文章图表全文连续编号；
- Word 原生脚注 / 尾注样式；
- `Bibliography` 与“参考文献条目”悬挂缩进样式；
- 与 Zotero / EndNote 等引用管理器共存，不主动改写第三方引用字段；
- 图表来源、摘要、关键词、作者信息、日期、参考文献等辅助样式。

具体说明见 [`docs/结构化思考.md`](docs/结构化思考.md)、[`docs/图表与引用.md`](docs/图表与引用.md) 和 [`docs/脚注与参考文献.md`](docs/脚注与参考文献.md)。

## 快捷键

不会快捷键也没关系，可以直接从 Word 的“样式”区域操作。

| 用途 | Windows | macOS |
|---|---|---|
| 一级标题 | `Ctrl + Alt + 1` | `⌘ + ⌥ + 1` |
| 二级标题 | `Ctrl + Alt + 2` | `⌘ + ⌥ + 2` |
| 三级标题 | `Ctrl + Alt + 3` | `⌘ + ⌥ + 3` |
| 四级标题 | `Ctrl + Alt + 4` | `⌘ + ⌥ + 4` |
| 正文 | `Ctrl + Alt + Z` | `⌘ + ⌥ + Z` |
| 表格文字 | `Ctrl + Alt + B` | `⌘ + ⌥ + B` |
| 引用 / 特别内容 | `Ctrl + Alt + Q` | `⌘ + ⌥ + Q` |
| 插入脚注 | `Ctrl + Alt + F` | `⌘ + ⌥ + F` |

某个快捷键如果被系统、输入法或插件占用，直接使用 Word 样式即可，不影响标题编号和文档结构。

## 为什么使用 `.dotx`？

`.dotx` 是 Word 模板格式。双击时，Word 会创建一篇新的文档，而不是直接修改模板本身。因此不需要先复制模板，也不会触发 VBA 宏安全提示。

第一次打开时只需要认识三样东西：**标题、一级标题、正文**。把占位文字换成自己的内容即可；以后需要新章节，再使用“标题 1 / 标题 2 / 标题 3 / 标题 4”。

## 兼容性与测试

项目会对 **24 个成品模板**做多层自动回归：

- Windows、macOS、Linux 三个平台重新从源码生成并检查 OOXML 结构；
- 校验四级编号、平台字体、快捷键、常用结构、分节、页码、页眉页脚、题注、脚注 / 尾注和参考文献样式；
- 检查没有 VBA 宏；
- 主构建把全部 24 个模板转换成 PDF 做布局冒烟测试；
- 发布前再审计两个用户 ZIP，确认每个平台恰好包含 12 个 `.dotx`、快速入门文件，并且没有宏模板或安装程序。

自动化检查不会启动真正的 Microsoft Word，所以不会把“结构检查通过”写成“所有 Word 版本都已真机验证”。详细范围见 [`docs/兼容性与测试.md`](docs/兼容性与测试.md)。

## 给维护者

模板、预览图和下载包都由脚本自动生成；不要手工维护 24 份二进制模板。

```text
word-writing-templates/
├── templates/                 # 自动生成：24 个 .dotx
├── release/                   # 自动生成：Windows / macOS 用户 ZIP
├── docs/assets/previews/      # 自动生成：6 张编号预览图
├── docs/                      # 用户说明与兼容性记录
├── scripts/                   # 生成、后处理、校验和发布审计
└── .github/workflows/         # 自动构建与跨平台检查
```

本地核心检查：

```bash
pip install -r requirements-dev.txt
python scripts/build_templates.py
python scripts/reference_support.py
python scripts/verify_templates.py
python scripts/compatibility_check.py
python scripts/manuscript_check.py
python scripts/reference_check.py
python scripts/stability_check.py
python scripts/make_quickstart.py
python scripts/make_previews.py   # 需要 LibreOffice + Noto CJK 字体
```

详细维护说明见 [`MAINTAINERS.md`](MAINTAINERS.md)，贡献说明见 [`CONTRIBUTING.md`](CONTRIBUTING.md)。
