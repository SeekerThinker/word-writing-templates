# Word 结构化思考与写作模板集

**让思路有层级，让结构可调整，让想法持续生长。**

这套模板最核心的初衷不是“把 Word 排得更漂亮”，而是**用结构化记录与写作辅助思考**。标题层级帮助你把想法、笔记、问题和材料分组、命名、排序并建立关系；内容变多以后，Word 的导航窗格会把这些关系持续呈现在眼前，方便检查遗漏、重复、层级和顺序。

**模板不会替你思考，但会让思考的结构更容易被看见、检查和重组。** 你可以只用它整理一个问题、长期积累笔记和材料；如果以后需要写文章、报告或书稿，同一套标题结构可以继续使用，不必重新搬运。编号、目录、页码、题注和参考文献等能力负责减少排版摩擦，把注意力留给内容本身。

> 项目的优先顺序是：**思考 → 结构 → 记录 / 写作 → 排版。**
>
> **整理和积累本身就是完整用途；成稿是可选延伸，不是必须的终点。**

## v4：减少选择，直接开始

v4 不再让用户在“直接开始版”和“带常用结构版”之间做选择。

现在是 **6 种编号 × 2 个平台 = 12 个用户模板**。每个模板都已经准备好 `标题 1 / 标题 2 / 标题 3 / 标题 4`、正文，以及前言 / 摘要、作者信息、目录、参考文献、页码、题注、脚注等常用结构。

打开模板后可以直接记录、整理或展开内容。暂时不用的区块可以留在文件里，需要时填写，不需要时删除；这些辅助区块使用非大纲样式，**不会挤进导航窗格干扰你的标题结构**。

这样，日常整理、长期积累和可能的后续成稿都可以留在同一份 Word 文档里，不需要为了改变用途重新搬运内容。

## 30 秒开始

1. 下载与你电脑对应的 ZIP；
2. 进入“书籍模板”或“文章模板”；
3. 双击喜欢的 `.dotx`；
4. 把占位文字换成自己的内容；
5. 需要拆分时用“标题 2 / 标题 3 / 标题 4”，积累一些内容后打开 **Word 导航窗格**，只看标题检查整体。

如果主要用于日常笔记、研究材料或整理思路，通常从“文章模板”开始更轻便；这并不意味着内容以后必须写成文章。

## 为什么这能辅助思考

把内容放进标题层级，本质上是在不断回答：

- 这一部分到底在讲什么？
- 它属于哪个更大的主题？
- 哪些内容应该并列，哪些应该从属？
- 哪里重复了，哪里缺了一块？
- 现在的顺序是否最清楚？

当内容越来越多、开始觉得“有点乱”时，可以暂时不改句子，只看导航窗格里的标题，问自己五件事：**并列吗？单一吗？完整吗？重复吗？顺序对吗？**

更完整的方法见 [`docs/结构化思考.md`](docs/结构化思考.md)。

## 模板里已经准备好的可选成稿结构

这些能力不是项目的终点，也不是开始使用的前置条件。它们存在的意义，是在你**确实需要**把内容整理成正式文稿时，不必重新搭一套排版结构。

### 书籍模板

预置书名页、作者、前言、自动目录、正文、附录、参考文献；前置部分使用罗马页码，正文从 `1` 重新编号。一级章标题自动另起新页，并预置镜像页边距、装订线、奇偶页页眉和外侧页码。

### 文章模板

预置作者、单位、日期、摘要、关键词、正文、参考文献以及从第 `1` 页开始的页码。

这些区块都是**可选**的。保留它们不会妨碍用标题层级整理思路；不需要时可以删除文字内容。涉及书籍分节符时，建议先读 [`docs/常用结构版.md`](docs/常用结构版.md) 里的删除说明，避免误删分节符改变页码体系。

## 图表、脚注与参考文献

模板继续使用 Word 原生能力：

- “图 / 表”题注和交叉引用；
- 书籍图表按一级章编号，文章图表全文连续编号；
- 原生脚注 / 尾注样式；
- `Bibliography` 与“参考文献条目”悬挂缩进样式；
- 与 Zotero / EndNote 等引用管理器共存，不主动改写第三方引用字段。

具体见 [`docs/图表与引用.md`](docs/图表与引用.md) 和 [`docs/脚注与参考文献.md`](docs/脚注与参考文献.md)。

## 为什么使用 `.dotx`

`.dotx` 是 Word 模板格式。双击时，Word 会创建一份新的文档，而不是直接修改模板本身。项目不使用 VBA 宏，因此不会要求用户开启宏权限。

## 兼容性与测试

v4 的**用户产品矩阵是 12 个模板**。构建系统目前仍会生成 v3 的历史双版本副本作为内部过渡产物，但 Release ZIP 和在线选择器只暴露 12 个统一模板。

自动化会检查 OOXML 结构、平台字体、快捷键、标题编号、分节、页码、页眉页脚、题注、脚注 / 尾注、参考文献样式，以及“可选结构不进入导航窗格”这一 v4 原则。主构建会把 12 个用户模板转换成 PDF 做布局冒烟测试，并审计 Windows / macOS 两个下载 ZIP。

这些检查**不会启动真正的 Microsoft Word**，所以不会把结构检查冒充成真机验证。详细范围见 [`docs/兼容性与测试.md`](docs/兼容性与测试.md)。

## v3 用户

v3.0.1 的“直接开始版 + 带常用结构版”仍保留在历史 Release 中。已经写成 `.docx` 的文档不需要迁移，也不需要重新套模板。

v4 是新的用户起点：**减少选择，而不是减少能力。**
