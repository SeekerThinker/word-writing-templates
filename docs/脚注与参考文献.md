# 脚注、尾注与参考文献

v2.9 起，全部 24 个模板统一整理了脚注、尾注和参考文献相关样式。目标不是替你决定某一种引用规范，而是让 Word 自己的注释功能、手工参考文献，以及 Zotero / EndNote 等引用管理工具更容易和模板共存。

## 脚注：直接用 Word 原生功能

Windows 可以使用 `Ctrl + Alt + F`，macOS 可以使用 `Command + Option + F`；也可以从 Word 的“引用”区域插入脚注。

模板统一整理了 Word 的 `Footnote Text` 与 `Footnote Reference` 样式：

- 脚注正文使用平台对应的中文正文字体；
- 默认 9 pt、单倍行距，适合作为正文下方的补充说明；
- 脚注编号保持上标显示；
- 不使用宏，也不把脚注伪装成页脚普通文字。

脚注编号本身仍由 Word 管理。模板不会强制“每页重新编号”或“每章重新编号”，因为学校、期刊和出版社的要求差异很大。

## 尾注

如果你的写作规范要求把注释集中放到文末，可以直接使用 Word 的“插入尾注”。模板同样整理了 `Endnote Text` 与 `Endnote Reference` 样式，使尾注和脚注保持一致的字体与字号逻辑。

模板不会自动把脚注转换成尾注，也不会替你决定应该使用哪一种。需要转换时使用 Word 自己的脚注 / 尾注设置即可。

## 参考文献条目

模板现在提供两套相关样式：

- **`Bibliography`**：Word 内置参考文献样式，适合 Word 自己生成的参考文献，也可以作为通用基础样式；
- **“参考文献条目”**：在 Word“样式”区域可以直接选择的中文样式，方便手工录入或最终整理。

两者默认都使用约 21 pt 的悬挂缩进：第一行靠左，第二行及以后向右缩进。长参考文献换行时更容易辨认每一条的起点。

> “参考文献”样式仍用于参考文献这一节的标题；“参考文献条目”才用于下面一条一条的文献内容。

## Zotero / EndNote 等引用管理工具怎么配合

这套模板**不内置 Zotero、EndNote，也不要求安装任何引用插件**。如果你本来就在用这些工具，推荐让引用管理器继续负责：

- 正文里的引文 / 引用字段；
- 作者—年份或数字编号格式；
- 参考文献的具体排序与标点；
- 学校、期刊或出版社要求的 CSL / 输出样式。

模板只提供一个干净的 Word 文档环境和可选的段落样式，不会主动改写第三方引用字段，也不会把引用转换成普通文字。

如果引用管理器刷新参考文献后重新覆盖了段落格式，这是引用管理器自己的输出行为。写作过程中优先保证引用字段可继续刷新；最后交稿前，再按目标规范决定是否需要额外整理版式。

## 一个很重要的习惯：不要手工改字段内部内容

使用 Word 自带引用、Zotero、EndNote 或其他引用工具时，正文中的引用往往不是普通文字，而是字段或插件维护的数据。

因此写作阶段建议：

1. 需要新增 / 删除引用时，通过对应的 Word 功能或引用管理器操作；
2. 不要为了“看起来对”而直接改字段内部生成的编号；
3. 不要在还要继续修改文稿时把全部引用字段转成纯文本；
4. 最终投稿系统明确要求纯文本时，再保留一份可编辑原稿后处理副本。

这样能避免“前面加了一条文献，后面几十个编号全要手改”的灾难。

## 和 v2.8 图表引用的关系

图表题注与正文交叉引用仍按 [`图表与引用.md`](图表与引用.md) 的方式使用。它们和脚注 / 文献引用都是 Word 的结构化能力，但用途不同：

- 图表：`图 / 表` 题注 + 交叉引用；
- 注释：脚注 / 尾注；
- 学术文献：Word 引用功能或 Zotero / EndNote 等管理器；
- 最终文献列表：引用管理器生成，或使用 `Bibliography / 参考文献条目` 样式手工整理。

## 兼容性边界

自动检查会验证 24 个模板都包含：

- `Footnote Text / Footnote Reference`；
- `Endnote Text / Endnote Reference`；
- `Bibliography`；
- “参考文献条目”；
- 正确的平台中文字体、脚注 / 尾注上标和参考文献悬挂缩进；
- 文档没有启用会阻止正常编辑的文档保护。

这些仍属于 OOXML 结构检查。Zotero、EndNote 的具体版本、学校定制样式以及 Microsoft Word 插件环境很多，项目不会据此声称“所有引用管理器版本都已真机兼容”。真实兼容性仍以实际 Word 使用反馈为准。
