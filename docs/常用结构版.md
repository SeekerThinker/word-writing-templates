# 常用结构版

每一种章节编号现在都有两个版本，但普通用户不需要因此多学任何东西。

## 直接开始版

这是默认版本，也是在线选择向导优先下载的版本。

打开后只有：

- 文档标题；
- 第一个一级标题；
- 第一段正文。

适合想马上开始写、以后需要什么再添加什么的人。

## 带常用结构版

如果你希望打开 Word 时就有一套常见写作骨架，可以使用文件名带 **“常用结构”** 的模板。

### 书籍

预置：

- 前言（可选）；
- 自动目录；
- 第一章与正文起点；
- 附录（可选）；
- 参考文献（可选）。

目录使用 Word 的目录域，会根据标题自动更新。如果打开后没有立即刷新，在目录上右键选择“更新域 / 更新目录”即可。

### 文章

预置：

- 摘要（可选）；
- 关键词；
- 第一个一级标题与正文起点；
- 参考文献（可选）。

不需要的区块直接删除即可，不会影响标题自动编号。

## 下载包里在哪里？

每个平台的 ZIP 仍然把最简单的模板放在第一层：

```text
书籍模板/
├─ 书籍-中文传统.dotx
├─ 书籍-章节数字.dotx
├─ 书籍-纯数字.dotx
└─ 带常用结构/
   ├─ 书籍-中文传统-常用结构.dotx
   ├─ 书籍-章节数字-常用结构.dotx
   └─ 书籍-纯数字-常用结构.dotx

文章模板/
├─ 文章-中文论文.dotx
├─ 文章-数字层级.dotx
├─ 文章-中文简洁.dotx
└─ 带常用结构/
   ├─ 文章-中文论文-常用结构.dotx
   ├─ 文章-数字层级-常用结构.dotx
   └─ 文章-中文简洁-常用结构.dotx
```

所以拿不准时，不用研究：**直接双击第一层模板即可。** 只有明确想要前言、摘要、目录、参考文献等现成骨架时，再进入“带常用结构”文件夹。

## 额外样式

两个版本都带有 `结构标题`、`摘要`、`关键词`、`参考文献` 等样式。这样即使一开始选择了“直接开始版”，后面也可以在 Word 的“样式”区域继续添加这些结构，而不必换模板。
