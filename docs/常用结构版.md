# v4 统一模板里的可选成稿结构

v4 开始，每一种章节编号只保留**一个用户模板**。不再区分“直接开始版”和“带常用结构版”。

这并不是减少功能，而是减少选择：模板把思考阶段和成稿阶段需要的能力放在同一份 Word 文件里。

## 一套模板，两种使用深度

刚开始写时，你只需要关心：

- 文档标题；
- `标题 1 / 标题 2 / 标题 3 / 标题 4`；
- 正文；
- Word 导航窗格。

写到成稿阶段时，再使用已经预置的作者信息、前言、摘要、目录、参考文献、页码、题注等结构。

暂时不用的区块可以留在文档中；需要时填写，不需要时删除。

## 为什么这些区块不会干扰导航窗格

前言、摘要、作者信息、目录标题、参考文献等使用专门的辅助样式，其中“结构标题”被设为**非大纲级别**。

因此它们可以存在于文档里，但不会像 `标题 1 / 标题 2 / 标题 3 / 标题 4` 一样进入导航窗格。导航窗格仍然主要呈现你的论述结构，也就是思考结构。

这正是 v4 合并两套模板的前提：**完整结构可以存在，但应该安静。**

## 书籍模板包含什么

预置：

- 独立书名页；
- 作者占位信息（可选）；
- 前言（可选）；
- 自动目录；
- 第一章与正文起点；
- 附录（可选）；
- 参考文献（可选）。

同时预置长文分页与打印逻辑：书名页不显示页码；前言和目录使用小写罗马页码 `i, ii, iii…`；正文进入新的节，并从阿拉伯数字 `1` 重新开始。

每个“标题 1”自动另起新页；书籍启用镜像页边距并预留装订空间。正文奇数页页眉显示当前章节，偶数页页眉显示书名；正文页码放在页面外侧，前置部分页码保持居中。

页眉使用 Word 的 `STYLEREF` 域读取书名与“标题 1”；目录使用 Word 原生目录域。内容变化后，可以在 Word 中更新域 / 更新目录。

## 文章模板包含什么

预置：

- 作者；
- 单位（可选）；
- 日期（可选）；
- 摘要（可选）；
- 关键词；
- 第一个一级标题与正文起点；
- 参考文献（可选）；
- 从 `1` 开始的居中页码。

这些元信息使用独立样式，不会改变标题自动编号，也不会进入以标题层级为主的导航结构。

## 哪些内容可以直接删除

文章模板里的作者、单位、日期、摘要、关键词、参考文献等文字区块，一般都可以按需要直接删除。

书籍模板也可以删除前言、附录、参考文献等**文字内容**。但书籍的前置部分和正文之间包含分节符，用来维持罗马页码、正文重新从 `1` 开始以及不同页眉页脚。

因此：

- 只是不写前言：删除前言标题和正文即可；
- 不需要附录 / 参考文献：删除对应文字即可；
- 不想显示目录：可以删除目录内容；
- 如果要连同整段前置部分一起删除，注意不要顺手删除正文前的分节符，否则页码和页眉可能跟着改变。

这也是为什么项目更推荐“暂时不用就留着”，而不是要求用户一开始先清理模板。

## 下载包现在更简单

每个平台只有 6 个用户模板：

```text
书籍模板/
├─ 书籍-中文传统.dotx
├─ 书籍-章节数字.dotx
└─ 书籍-纯数字.dotx

文章模板/
├─ 文章-中文论文.dotx
├─ 文章-数字层级.dotx
└─ 文章-中文简洁.dotx
```

用户只需要决定：**写书还是写文章、喜欢哪种编号、Windows 还是 macOS。**

更详细的分页、页码、页眉与打印说明见 [`成稿版式.md`](成稿版式.md)。
