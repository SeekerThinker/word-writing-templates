# 常用结构版

每一种章节编号都有两个版本，但普通用户不需要因此多学任何东西。

## 直接开始版

这是默认版本，也是在线选择向导优先下载的版本。

打开后只有：

- 文档标题；
- 第一个一级标题；
- 第一段正文。

适合想马上开始写、以后需要什么再添加什么的人。

## 带常用结构版

如果你希望打开 Word 时就有一套更接近成稿的常见写作骨架，可以使用文件名带 **“常用结构”** 的模板。

### 书籍

预置：

- 独立书名页；
- 作者占位信息（可选）；
- 前言（可选）；
- 自动目录；
- 第一章与正文起点；
- 附录（可选）；
- 参考文献（可选）。

书籍结构版还把常见的长文分页与打印逻辑一起预置好了：书名页不显示页码；前言和目录使用小写罗马页码 `i, ii, iii…`；正文换到新的节，并从阿拉伯数字 `1` 重新开始。

从 v2.7 起，每个“标题 1”会自动另起新页；书籍同时启用镜像页边距并预留装订空间，更适合双面打印。正文奇数页页眉显示当前章节，偶数页页眉显示书名；正文页码放在页面外侧，前置部分页码保持居中。

页眉使用 Word 的 `STYLEREF` 域读取“标题”和“标题 1”样式，因此把书名与章节标题替换成自己的内容后，Word 更新域时页眉可以随之更新。目录同样使用 Word 的目录域；如打开后没有立即刷新，在目录上右键选择“更新域 / 更新目录”即可。

> 模板不会强制每一章必须从奇数页开始。若出版社明确要求“章节从右页起”，建议在最终交稿排版阶段按要求使用“奇数页分节符”，这样不会在写作过程中产生难以理解的空白页。

### 文章

预置：

- 作者；
- 单位（可选）；
- 日期（可选）；
- 摘要（可选）；
- 关键词；
- 第一个一级标题与正文起点；
- 参考文献（可选）；
- 从 `1` 开始的居中页码。

作者、单位和日期使用单独样式，不需要时可以直接删除；其他可选区块也一样。v2.7 进一步调整了标题与作者信息之间的视觉间距，使第一页更接近成稿。删除这些内容不会影响标题自动编号。

## 下载包里在哪里？

每个平台的 ZIP 仍然把最简单的模板放在第一层：

```text
书籍模板/
├─ 书籍-中文传统.dotx
├─ 书籍-章节数字.dotx
├─ 书籍-纯数字.dotx
└─ 带常用结构/
   ├─ 书籍-中文传统-常用结构.dotx
   ├─ 书籍-章节数字-常用结构.dotx
   └─ 书籍-纯数字-常用结构.dotx

文章模板/
├─ 文章-中文论文.dotx
├─ 文章-数字层级.dotx
├─ 文章-中文简洁.dotx
└─ 带常用结构/
   ├─ 文章-中文论文-常用结构.dotx
   ├─ 文章-数字层级-常用结构.dotx
   └─ 文章-中文简洁-常用结构.dotx
```

所以拿不准时，不用研究：**直接双击第一层模板即可。** 只有明确想要前言、摘要、目录、页码、页眉、双面打印设置、参考文献等现成骨架时，再进入“带常用结构”文件夹。

## 额外样式

两个版本都带有 `结构标题`、`摘要`、`关键词`、`参考文献`、`作者信息`、`日期` 等样式。这样即使一开始选择了“直接开始版”，后面也可以在 Word 的“样式”区域继续添加这些结构，而不必换模板。

更详细的分页、页码、页眉与打印说明见 [`成稿版式.md`](成稿版式.md)。
