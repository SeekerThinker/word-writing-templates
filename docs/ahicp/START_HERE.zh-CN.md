# AHICP 接管入口

本仓库采用 AHICP 作为人机协作与项目治理层。本次升级只接入治理接口，不改变项目正文、研究结论、产品内容或历史文件。

接管顺序：

1. 阅读 `AHICP_MANIFEST.yaml` 与 `AHICP_CONTEXT_INTERFACE.yaml`。
2. 阅读 `docs/ahicp/WORKING_MEMORY.md`、`DECISION_LOG.md` 和 `APPROVED_FRAMEWORK.md`。
3. 阅读 `project-stack.yaml` 与 `project-stack.lock.yaml`。
4. 在进行实质性内容修改前，完成 `docs/ahicp/ONBOARDING_REPORT.md`。

AI 的建议不是人类批准的决定。涉及内容、发布、权限、公开范围和外部部署的改变，必须保留人类审批记录。
