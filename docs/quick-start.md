# Quick start

[中文](快速开始.md) · [Project overview](../README.en.md) · [Open the English editor](https://seekerthinker.github.io/word-writing-templates/en/editor.html)

**Give your ideas levels before worrying about layout.** Use headings to organize thoughts, notes, questions, and sources, and keep the whole visible as you examine relationships. Notes and research collections can remain just that; the same structure can also grow into a paper, report, or book.

## Path one: start in the browser

1. Open the [English online editor](https://seekerthinker.github.io/word-writing-templates/en/editor.html). The heading tree is on the left; the full document is continuously editable on the right by default.
2. Name the document and write down a thought. As material grows, use Heading 1–4 to group and name sections; select an outline heading to jump to its text, or drag a heading to move its whole section.
3. Insert real tables and footnotes when needed. Focus shows the current section; Page preview is read-only and only approximates paper layout.
4. Choose document language, numbering, and the intended Word platform. Export Word to get a `.docx` and continue using real headings, the Navigation Pane, tables, and footnotes in desktop Word.

**Download Backup JSON regularly.** A draft is stored in this browser, not synced to the cloud; clearing site data, switching devices, or private browsing can remove that draft. Import backup restores JSON. An exported `.docx` is for Word, and cannot currently be imported back into this browser editor. See the [online editor guide](online-editor.md).

## Path two: start directly in Word

1. Download the [Windows package](https://github.com/SeekerThinker/word-writing-templates/releases/latest/download/Word-Writing-Templates-Windows.zip) or [macOS package](https://github.com/SeekerThinker/word-writing-templates/releases/latest/download/Word-Writing-Templates-macOS.zip).
2. After unzipping, pick a book or article template and a numbering style. The article presets are often lighter for everyday notes. In v4, each numbering style has one template: 12 public `.dotx` files across the two platforms.
3. Double-click `.dotx`: Word creates a new document, leaving the template unchanged. Replace sample text and begin writing.
4. Apply real Heading 1–4 using Word's Home → Styles, rather than merely enlarging or bolding text. Open View → Navigation Pane and switch to the headings view to inspect the whole.

Optional preface, abstract, contents, and references can remain until you need them. They use non-outline styles and do not clutter your heading tree. Book templates contain section breaks that control front-matter and body pagination; be careful not to delete them when removing large front-matter sections. The detailed [front-matter guide](常用结构版.md) is currently in Chinese.

## A five-minute thinking exercise

Write the question you want to explore as your document title. Create a few main Heading 1 topics, then split complex topics into Heading 2–4. Inspect only the heading tree: Which parts are peers or children? What is missing, repeated, or out of order? Rename a heading or move a section, then return to the body.

**You do not need a perfect outline first.** Heading levels can evolve with your thinking; organizing material is useful in itself. When you need a finished document, Word can use the same headings for navigation, numbering, and a table of contents alongside native page numbers, captions, footnotes, and references. [Word usage guide](https://seekerthinker.github.io/word-writing-templates/en/guide.html)

Browser and Word share Windows/macOS shortcuts for headings, body, table, quote, and footnote. See the editor's shortcut panel or [README](../README.en.md); shortcuts are optional.
