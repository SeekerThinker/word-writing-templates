# 图表题注与交叉引用

v2.8 起，全部 24 个模板都预置了 Word 原生的中文图表题注设置。目标是让图号、表号和正文里的“见图……”不要靠手工维护，也不需要宏、插件或脚本。

## 最简单的用法

插入图片或表格后，在 Microsoft Word 里打开 **“引用” → “插入题注”**。

模板已经预置两个中文标签：

- **图**：默认题注位置在对象下方；
- **表**：默认题注位置在对象上方。

Word 插入的题注会使用模板里已经整理好的 **Caption / 题注** 样式：居中、黑色、小于正文，并且不会跟随 Office 主题变成蓝色。需要写“来源：作者整理 / 数据来源……”时，可以使用模板里的 **“图表来源”** 样式。

## 编号规则

### 书籍模板

书籍模板把“图 / 表”设置成 **跟随一级章标题的章节编号**，分隔符使用连字符。

因此在数字章节方案里，常见效果会类似：

- `图 1-1`
- `图 1-2`
- `表 1-1`
- 到下一章后重新从该章的第 1 个图 / 表开始。

章节前缀来自 Word 的 **标题 1** 编号，所以如果你使用“中文传统”等中文章号方案，题注的章节部分也会跟随该标题编号的显示方式，而不是强行改成阿拉伯数字。

### 文章模板

文章模板使用全文连续编号：

- `图 1`、`图 2`、`图 3`……
- `表 1`、`表 2`、`表 3`……

这比按一级标题重新编号更适合一般论文、报告和长文章。

## 正文里引用图表

不要手工输入“见图 3”或“如表 2 所示”。图表一多，前面增删一个对象，后面的手工编号就很容易全部错位。

推荐使用 Word 的 **“引用” → “交叉引用”**：

1. 把光标放在正文需要引用图表的位置；
2. 打开“交叉引用”；
3. 选择对应的“图”或“表”题注类型；
4. 选择希望插入的内容，例如“仅标签和编号”；
5. 选择目标题注并插入。

这样正文中的引用是 Word 字段，而不是普通文字。图表顺序变化后，更新字段即可重新计算编号。

## 增删图表后如何刷新

目录、题注、交叉引用、页码和页眉都属于 Word 字段。模板已经开启“打开时请求更新字段”的设置，但不同 Word 版本的自动刷新行为可能略有差异。

如果看到编号没有立刻变化，可以：

- 在对应题注 / 交叉引用上右键，选择“更新域”；
- 或选中文档内容后执行 Word 的“更新域”命令。

菜单名称在不同 Word 版本中可能略有不同。

## 图表来源

模板新增 **“图表来源”** 样式，用来写例如：

`来源：作者根据公开数据整理。`

它默认使用较小、较浅的正文同系列字体并居中显示。它只是普通样式，不参与编号；不需要来源说明时可以不使用。

## 为什么不用宏自动插入？

这个项目一直优先保证普通用户双击 `.dotx` 就能写，不触发宏安全提示，也不要求安装插件。

所以 v2.8 选择 Word 自带的 **题注（Caption）+ 交叉引用（Cross-reference）** 机制：模板负责预置标签、编号规则和样式，Word 自己负责生成和更新字段。

## 兼容性边界

自动检查会验证：

- 24 个模板都包含“图 / 表”题注定义；
- 书籍模板启用按标题 1 的章节编号；
- 文章模板保持全文连续编号；
- Caption / 题注样式与“图表来源”样式存在并使用平台对应字体；
- 字段更新设置仍然开启。

这些属于 OOXML 结构检查。真正的“插入题注”对话框、交叉引用对话框以及字段刷新体验仍需要 Windows / Mac 的 Microsoft Word 真机反馈来验证。
