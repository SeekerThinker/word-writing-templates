# 快速开始

这套模板最重要的用途不是排版，而是**帮助你用结构组织思考**。你可以先写、再整理，也可以边写边调整层级；不需要在开始前把完整大纲一次想完。

你不需要先学习 Word 排版。第一次使用只做下面几步：

1. 下载与你的电脑系统对应的 ZIP：Windows 或 macOS。
2. 解压后进入“书籍模板”或“文章模板”。
3. **拿不准时，直接双击文件夹第一层的 `.dotx` 文件。**
4. Word 会自动新建文档。把“在这里输入……”和“从这里开始写作”替换成自己的内容即可。
5. 继续写正文；需要新章节时，再使用 Word 的“标题 1 / 标题 2 / 标题 3 / 标题 4”样式，或者使用模板快捷键。

不会快捷键也没关系。快捷键只是加速操作，模板的标题编号和结构并不依赖你必须使用快捷键。

## 把标题层级当成思考层级

写作时，可以把一个大主题放在“标题 1”，把它下面的问题或分论点放在“标题 2”；需要继续拆分时再使用“标题 3 / 标题 4”。

这样做的意义不只是自动编号。标题层级会把原本连续的文字变成可观察的结构，帮助你检查：哪些内容重复、哪里缺了一块、哪些主题应该并列、现在的顺序是否清楚。

当文档变长以后，打开 Word 的导航窗格，只看标题就能快速浏览全文结构。在支持该操作的 Word 桌面版本中，还可以从导航窗格拖动标题重新安排文档部分。不同平台或 Word 版本的具体界面可能略有差异。

更完整的思考方法见 [`结构化思考.md`](结构化思考.md)。

## 想要现成的写作骨架？

每个“书籍模板 / 文章模板”文件夹里都有一个 **“带常用结构”** 子文件夹。

- 书籍常用结构版：前言、自动目录、第一章、附录、参考文献；
- 文章常用结构版：摘要、关键词、一级标题、参考文献。

这些区块都是可选的，不需要时直接删除即可。普通用户如果不确定该不该用，继续使用第一层的“直接开始版”就好。

详细说明见 [`常用结构版.md`](常用结构版.md)。

## 写到长文时再学这些功能

- **导航窗格**：按标题浏览全文、检查整体结构；在支持拖动重排的 Word 桌面版本中，还可以移动文档部分。
- **目录**：需要目录时再插入即可；内容变化后使用 Word 的“更新目录 / 更新域”即可刷新。常用结构版书籍已经预置自动目录。
- **图表题注与交叉引用**：用 Word 的“引用 → 插入题注 / 交叉引用”，不要手工维护图号、表号。见 [`图表与引用.md`](图表与引用.md)。
- **脚注 / 尾注**：直接使用 Word 原生脚注或尾注；Windows 可用 `Ctrl + Alt + F` 插脚注，macOS 可用 `Command + Option + F`。
- **参考文献**：手工整理时可以给每条文献套用“参考文献条目”样式；如果使用 Zotero / EndNote，就继续让引用管理器维护引用字段和具体规范。见 [`脚注与参考文献.md`](脚注与参考文献.md)。

这些都不是开始写作的前置条件。下载、双击模板、替换占位文字，就可以直接开始。
