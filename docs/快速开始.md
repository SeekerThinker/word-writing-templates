# 快速开始

[English](quick-start.md) · [项目主页](../README.md) · [打开在线编辑器](https://seekerthinker.github.io/word-writing-templates/editor.html)

**先让思路有层级，再决定怎样呈现。** 这套工具先用标题帮你组织想法、笔记、问题和材料，再用可见的整体检查关系。你可以一直用来整理和积累，也可以沿着同一套结构继续写成报告或书稿。

## 路径一：直接在线开始

1. 打开[中文在线编辑器](https://seekerthinker.github.io/word-writing-templates/editor.html)；左侧是标题树，右侧默认可连续浏览、编辑全文。
2. 写下文档标题和第一个想法。内容变多以后，使用标题 1–4 分组和命名，点击左侧标题定位正文；也可以拖动标题移动整节。
3. 需要时插入真正的表格与脚注；「专注」只看当前节，「页面预览」只读、仅供大致观察纸张形态。
4. 选好文档语言、编号方案和以后使用 Word 的平台。点击「导出 Word」，下载 `.docx`，在本地 Word 中继续使用标题层级、导航窗格、表格和脚注。

**请定期点「备份 JSON」。** 浏览器草稿只保存在当前浏览器本地，不是云同步；清理站点数据、换设备或隐私模式都可能失去本地草稿。用「导入备份」恢复 JSON，`.docx` 则是供 Word 继续编辑的文件，当前不能直接导回网页编辑器。具体见 [在线编辑器说明](在线编辑器.md)。

## 路径二：直接在 Word 中开始

1. [下载 Windows 整包](https://github.com/SeekerThinker/word-writing-templates/releases/latest/download/Word-Writing-Templates-Windows.zip) 或 [macOS 整包](https://github.com/SeekerThinker/word-writing-templates/releases/latest/download/Word-Writing-Templates-macOS.zip)。
2. 解压后从「书籍」或「文章」中选喜欢的编号；日常笔记与研究整理通常可以先用文章模板。v4 每种编号只对应一个模板，共 12 个公共 `.dotx`。
3. 双击 `.dotx`；Word 根据模板新建一份文档，原模板不变。替换占位文字，开始记录。
4. 在 Word「开始 → 样式」中使用真正的「标题 1 / 2 / 3 / 4」，不要只手动加粗放大文字；从「视图」打开导航窗格并切到标题视图，检查整体。

暂时不用的前言、摘要、目录、参考文献等辅助区块可以保留或按说明删除，它们使用非大纲样式，不会挤进你的导航结构。书籍模板的分节符关系到罗马页码和正文重新编号，大幅删除前置部分前请先读 [常用结构版](常用结构版.md)。

## 五分钟做一次结构化思考

把真正想弄清楚的事情写成文档标题；写下几个大问题作为「标题 1」，再把需要拆分的内容放到「标题 2 / 3 / 4」。过一会儿只看标题树：哪些内容并列或从属，哪里遗漏、重复，顺序是否自然？改一个标题、移动一节，再回正文继续。

**不必先写出完美大纲。** 标题层级会随着思考改变；整理与积累本身就有价值。需要成稿时，Word 可以继续利用这些标题生成目录、编号，并提供页码、题注、脚注和引用等原生能力。[完整方法](结构化思考.md) · [Word 使用说明](https://seekerthinker.github.io/word-writing-templates/guide.html)

网页与 Word 的标题、正文、表格、引用和脚注采用对应的 Windows/macOS 共用快捷键；具体组合键可在网页「快捷键」面板或 [README](../README.md) 查看，不会快捷键也不影响使用。
