# 快速开始

这套模板最重要的用途不是排版，而是**帮助你用结构组织思考**。v4 开始，每一种编号只保留一个用户模板：不再区分“直接开始版”和“带常用结构版”。

模板里已经准备好前言、摘要、作者信息、目录、参考文献、页码等成稿结构，但你一开始完全可以不管它们。暂时不用就保留在那里，需要时填写，不需要时删除。

## 第一次使用只做 4 步

1. 下载与你电脑系统对应的 ZIP：Windows 或 macOS。
2. 解压后进入“书籍模板”或“文章模板”。
3. 选喜欢的编号，双击 `.dotx`。Word 会自动新建文档，原模板不会被改坏。
4. 找到正文起点，把占位文字换成自己的内容，然后开始写。

不会快捷键也没关系。快捷键只是加速操作，标题编号和结构并不依赖快捷键。

## 先做一次 5 分钟结构化思考

不要急着研究页码、目录或字体。先把模板当成一个帮助整理思路的工作区：

1. 把真正想弄清楚的事情写成文档标题；
2. 先写 3～5 个“标题 1”，把它们当成几个大问题或主要部分；
3. 某一部分还包含不同问题时，再拆成“标题 2”；
4. 打开 Word 的导航窗格，只看标题结构；
5. 如果顺序或层级看起来不自然，就先改结构，再选一个分支继续写正文。

这一轮不追求“正确大纲”。目标只是把脑中的关系放到眼前，让后面的写作有一个可以随时检查和调整的结构。

## 为什么成稿区块不会打扰思考

前言、摘要、作者信息、目录、参考文献等区块使用的是**非大纲样式**。它们可以留在文档里，但不会像“标题 1 / 标题 2 / 标题 3 / 标题 4”那样进入导航窗格。

因此导航窗格主要呈现的是你的**思考结构**，而不是所有排版组件。

写到一半觉得内容越来越乱时，可以先不要修改句子，只看导航窗格里的标题，并问自己五件事：**同级内容是否并列、一个标题是否只做一件事、有没有缺口、有没有重复、现在的顺序是否最好理解。**

更完整的方法见 [`结构化思考.md`](结构化思考.md)。

## 模板里已经准备好的可选结构

书籍模板预置：书名页、作者、前言、自动目录、正文、附录、参考文献，以及前置 / 正文页码、双面打印页边距和奇偶页页眉。

文章模板预置：作者、单位、日期、摘要、关键词、正文、参考文献和页码。

这些结构都不是开始写作的前置条件。你可以先专心写标题和正文，等需要成稿时再回来处理。

> 书籍模板含分节符。删除前言或目录文字没有问题，但如果要大幅删除整段前置部分，建议先看 [`常用结构版.md`](常用结构版.md)，避免误删分节符导致页码或页眉逻辑变化。

## 写到长文时再用这些能力

- **导航窗格**：按标题浏览全文、检查整体结构；在支持拖动重排的 Word 桌面版本中，还可以移动文档部分。
- **目录**：书籍模板已经预置自动目录；内容变化后使用 Word 的“更新目录 / 更新域”刷新。
- **图表题注与交叉引用**：用 Word 的“引用 → 插入题注 / 交叉引用”，不要手工维护图号、表号。见 [`图表与引用.md`](图表与引用.md)。
- **脚注 / 尾注**：直接使用 Word 原生脚注或尾注；Windows 可用 `Ctrl + Alt + F`，macOS 可用 `Command + Option + F`。
- **参考文献**：手工整理时可用“参考文献条目”样式；如果使用 Zotero / EndNote，就继续让引用管理器维护字段和具体规范。见 [`脚注与参考文献.md`](脚注与参考文献.md)。

一句话：**先用标题层级想清楚，再让同一份 Word 文档自然长成成稿。**
