# Windows 使用说明

推荐 Microsoft Word for Windows。

## 快捷键

- 一级标题：`Ctrl + Alt + 1`
- 二级标题：`Ctrl + Alt + 2`
- 三级标题：`Ctrl + Alt + 3`
- 四级标题：`Ctrl + Alt + 4`
- 正文：`Ctrl + Alt + Z`
- 表格文字：`Ctrl + Alt + B`
- 引用：`Ctrl + Alt + Q`
- 插入脚注：`Ctrl + Alt + F`

Windows 版模板优先使用 Windows 常见中文字体，减少跨平台替换导致的版式变化。

如果某个快捷键被 Word 插件或系统软件占用，仍可通过 Word 的“样式”区域正常使用全部模板功能。
