# 兼容性验证记录

这个页面区分两类结果：

- **自动结构检查**：由 GitHub Actions 自动执行，检查 `.dotx` / OOXML 结构、编号、字体、快捷键映射、中文路径和宏文件缺失。
- **真实 Word 验证**：由真实 Windows / Mac 电脑上的 Microsoft Word 桌面版完成，并通过公开 Issue 留下可追踪记录。

## 怎样成为“真实 Word 已验证”

为了避免把零散的“能打开”反馈夸大为完整验证，一个公开测试记录至少应包含：

1. 操作系统；
2. Word 版本；
3. 测试模板名称；
4. `.dotx` 能创建新文档；
5. 标题 1～4 的多级编号正常；
6. 保存为 `.docx` 后重新打开仍正常。

目录、导航窗格和快捷键属于推荐补充项。快捷键可能受系统、输入法、Word 插件或用户自定义设置影响，因此“快捷键冲突”不会自动判定整个模板不兼容。

## 帮忙验证

普通用户可以按 [`真实Word验收.md`](真实Word验收.md) 的 3～5 分钟清单测试，然后使用：

**[Word 真机兼容性反馈模板](https://github.com/SeekerThinker/word-writing-templates/issues/new?template=word_compatibility_report.md)**

提交结果。不需要提供个人信息，也不需要上传真实写作内容。
