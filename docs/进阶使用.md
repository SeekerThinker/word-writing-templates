# 进阶使用

## 自动目录

正确使用“标题 1 / 2 / 3 / 4”后，可以通过 Word 的“引用 → 目录”自动生成目录。正文调整后更新目录即可。

## 导航窗格

打开 Word 的导航窗格后，可以按标题层级浏览全文结构。长文写作时尤其方便。

## 拖动整章

在导航窗格中拖动某个标题，Word 会把该标题下的内容一起移动，因此可以快速调整章节顺序。移动后建议快速检查一次正文。

## 多窗口

同一篇文档可以打开多个窗口，同时查看不同章节。两个窗口实际上编辑的是同一个文档，适合前后对照修改。

## 大纲视图和 Web 版式

大纲视图适合从结构角度整理长文；Web 版式在单屏多窗口时更容易自由缩放阅读。
