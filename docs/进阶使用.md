# 进阶使用

## 自动目录

正确使用“标题 1 / 2 / 3 / 4”后，可以通过 Word 的“引用 → 目录”自动生成目录。内容调整后更新目录即可。只有需要正式目录时才使用这一功能，日常整理并不依赖它。

## 导航窗格

打开 Word 的导航窗格后，可以按标题层级浏览整份文档的结构。内容较多时尤其方便：你可以专心处理眼前一部分，也可以随时退回来观察整体。

## 拖动整块内容

在支持这一操作的 Word 桌面版本中，从导航窗格拖动某个标题，会把该标题下的内容一起移动，因此可以快速调整顺序。移动后建议快速检查一次相关内容。

## 多窗口

同一份文档可以打开多个窗口，同时查看不同部分。两个窗口实际上编辑的是同一个文档，适合前后对照、材料整理和长文修改。

## 大纲视图和 Web 版式

大纲视图适合从结构角度整理复杂内容；Web 版式在单屏多窗口时更容易自由缩放阅读。
