# 真实 Microsoft Word 验收清单

这份清单给愿意帮忙做 **Windows / Mac 真机测试** 的普通用户使用。不需要懂 GitHub、OOXML 或 Word 排版原理，整个过程大约 3～5 分钟。

> 自动化测试已经检查模板结构；这里要验证的是“在真正的 Microsoft Word 里，普通用户是否真的顺手”。

## 开始前

1. 从 [最新版 Release](https://github.com/SeekerThinker/word-writing-templates/releases/latest) 下载与你电脑对应的 ZIP。
2. 解压后任选一个 `.dotx` 模板。第一次测试推荐：
   - 写书：`书籍-中文传统.dotx`
   - 写文章：`文章-中文论文.dotx`
3. 双击模板，用 **Microsoft Word 桌面版** 打开。

## 只需要检查这些

请边用边看下面几项，正常就打勾；不想测的项目可以写“未测试”。

- [ ] **能打开**：双击 `.dotx` 后，Word 创建了一篇新的文档，而不是直接修改模板文件。
- [ ] **标题编号正常**：把一级标题改成自己的文字，编号仍然存在。
- [ ] **多级标题正常**：分别添加“标题 1 / 标题 2 / 标题 3 / 标题 4”，编号层级看起来正确。
- [ ] **正文正常**：正文能正常输入，字体、字号和行距没有明显异常。
- [ ] **保存再打开正常**：保存为普通 `.docx`，关闭 Word，再重新打开，标题和编号没有坏掉。
- [ ] **目录正常（可选）**：插入目录后，能看到各级标题；修改标题后“更新目录 / 更新域”能刷新。
- [ ] **导航窗格正常（可选）**：标题能出现在导航窗格中。
- [ ] **快捷键正常（可选）**：至少试一个标题快捷键和正文快捷键；如果被系统、输入法或插件占用，也请如实记录。

## 快捷键参考

| 用途 | Windows | macOS |
|---|---|---|
| 一级标题 | `Ctrl + Alt + 1` | `⌘ + ⌥ + 1` |
| 二级标题 | `Ctrl + Alt + 2` | `⌘ + ⌥ + 2` |
| 三级标题 | `Ctrl + Alt + 3` | `⌘ + ⌥ + 3` |
| 四级标题 | `Ctrl + Alt + 4` | `⌘ + ⌥ + 4` |
| 正文 | `Ctrl + Alt + Z` | `⌘ + ⌥ + Z` |
| 表格文字 | `Ctrl + Alt + B` | `⌘ + ⌥ + B` |
| 引用 / 特别内容 | `Ctrl + Alt + Q` | `⌘ + ⌥ + Q` |
| 插入脚注 | `Ctrl + Alt + F` | `⌘ + ⌥ + F` |

快捷键不是模板正常工作的前提。某个快捷键没反应时，请再从 Word 的“样式”区域试一次对应标题或正文；这样可以区分“模板结构问题”和“快捷键冲突”。
