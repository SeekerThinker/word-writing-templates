# 真实 Microsoft Word 验收清单

这份清单给愿意帮忙做 **Windows / Mac 真机测试** 的普通用户使用。不需要懂 GitHub、OOXML 或 Word 排版原理。

> 自动化测试已经检查模板结构；这里要验证的是“在真正的 Microsoft Word 里，普通用户是否真的顺手”。

## 开始前

1. 从 [最新版 Release](https://github.com/SeekerThinker/word-writing-templates/releases/latest) 下载与你电脑对应的 ZIP。
2. 解压后任选一个 `.dotx` 模板。v4 每一种编号只有一个用户模板。
3. 第一次测试推荐：
   - 写书：`书籍-中文传统.dotx`；
   - 写文章：`文章-中文论文.dotx`。
4. 双击模板，用 **Microsoft Word 桌面版** 打开。

## 建议检查这些

- **能打开**：双击 `.dotx` 后，Word 创建一篇新的文档，而不是直接修改模板文件。
- **标题编号正常**：把一级标题改成自己的文字，编号仍然存在。
- **多级标题正常**：分别添加“标题 1 / 标题 2 / 标题 3 / 标题 4”，编号层级正确。
- **正文正常**：正文能正常输入，字体、字号和行距没有明显异常。
- **保存再打开正常**：保存为普通 `.docx`，关闭 Word，再重新打开，标题和编号没有坏掉。
- **导航窗格正常（v4 重点）**：打开导航窗格，`标题 1 / 2 / 3 / 4` 能形成结构树；前言、摘要、参考文献等可选成稿区块**不应该挤进这棵标题树**。在支持拖动的桌面版本中，也可以试着移动一个标题，确认对应内容一起移动。
- **目录正常（书籍，可选）**：预置目录能更新；修改标题后“更新目录 / 更新域”能刷新。
- **页码 / 页眉正常（可选）**：书籍模板的书名页不显示页码，前言 / 目录显示 `i, ii, iii…`，正文从 `1` 重新开始；文章模板从第 `1` 页开始显示页码。
- **书籍章节换页（可选）**：在正文后新建一个“标题 1”，确认它自动从新页开始。
- **书籍奇偶页版式（可选）**：正文奇数页页眉显示当前章节、偶数页页眉显示书名；页码位于页面外侧。
- **书籍双面打印边距（可选）**：确认文档使用镜像页边距并预留装订空间。
- **图表题注（可选）**：插入图片或表格，用“引用 → 插入题注”，确认可以选择“图 / 表”标签；书籍按章编号，文章连续编号。
- **交叉引用（可选）**：插入图表交叉引用，增删前面的图表后更新域，确认编号能跟着变化。
- **脚注 / 尾注（可选）**：插入一条脚注或尾注，确认正文较小、编号为上标，保存重开后仍正常。
- **参考文献条目（可选）**：使用“参考文献条目”样式输入一条会换行的文献，确认第二行出现悬挂缩进。
- **引用管理器（使用者可选）**：如果本来使用 Zotero / EndNote，可以插入一条引用并刷新参考文献，确认插件仍能正常更新字段。
- **可选成稿结构（可选）**：书籍能看到书名页、前言、目录、附录、参考文献；文章能看到作者、单位、日期、摘要、关键词、参考文献。暂时不用可以保留，删除普通文字后正文仍应正常。
- **快捷键正常（可选）**：至少试一个标题快捷键和正文快捷键；如果被系统、输入法或插件占用，也请如实记录。

> 书籍模板不会强制“每章必须从奇数页 / 右页开始”。如果出版社明确要求右页起章，那属于最终出版排版规则，不应把普通的“自动另起新页”误判为故障。

> 书籍前置部分和正文之间含分节符。完整验收不要求测试“删除整段前置部分”；误删分节符可能改变页码和页眉，这属于 Word 分节机制，不是普通用户第一次测试的必要项目。

## 快捷键参考

| 用途 | Windows | macOS |
|---|---|---|
| 一级标题 | `Ctrl + Alt + 1` | `⌘ + ⌥ + 1` |
| 二级标题 | `Ctrl + Alt + 2` | `⌘ + ⌥ + 2` |
| 三级标题 | `Ctrl + Alt + 3` | `⌘ + ⌥ + 3` |
| 四级标题 | `Ctrl + Alt + 4` | `⌘ + ⌥ + 4` |
| 正文 | `Ctrl + Alt + Z` | `⌘ + ⌥ + Z` |
| 表格文字 | `Ctrl + Alt + B` | `⌘ + ⌥ + B` |
| 引用 / 特别内容 | `Ctrl + Alt + Q` | `⌘ + ⌥ + Q` |
| 插入脚注 | `Ctrl + Alt + F` | `⌘ + ⌥ + F` |

快捷键不是模板正常工作的前提。某个快捷键没反应时，请再从 Word 的“样式”区域试一次对应标题或正文。
