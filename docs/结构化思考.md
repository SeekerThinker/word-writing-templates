# 结构化思考：让思路在 Word 里变得可见

这套模板最重要的目的不是“把文档排得更漂亮”，而是**用结构化写作辅助思考**。

> **让思路有层级，让结构可调整，让想法直接长成文章。**

模板不会替你思考。它做的事情更朴素：把你的想法放进可见的层级里，让你更容易发现它们之间的关系，并在写作过程中不断重新组织。

## 为什么层级能辅助思考

当你给一段内容决定“它是什么标题、属于哪一层、放在哪个主题下面”时，其实正在做几件重要的思考工作：

- **分组**：哪些内容属于同一个问题；
- **命名**：这一组内容到底在讨论什么；
- **排序**：哪些内容应该先讲，哪些应该后讲；
- **建立从属关系**：这是一个大问题，还是其中的一个子问题；
- **检查结构**：哪里重复、哪里缺失、哪里层级不对、哪里跳得太快。

结构化不会自动产生好观点，但会让混乱更容易被看见。很多时候，一段内容迟迟不知道该放在哪个标题下面，本身就是一个值得继续想的问题。

## Word 的导航窗格就是“全文结构视图”

只要正文使用 Word 的“标题 1 / 标题 2 / 标题 3 / 标题 4”样式，导航窗格就可以按标题显示整篇文稿的层级。

文档很短时，你可以只看正文。文档变长后，建议打开 Word 的导航窗格，把它当成全文的结构视图：

1. 用“标题 1”表示主要章节或主要论点；
2. 用“标题 2 / 3 / 4”继续拆分子问题；
3. 在导航窗格里查看整篇内容是否均衡、是否有重复或缺口；
4. 如果论述顺序需要调整，可以在导航窗格中拖动标题，连同该标题下面的内容一起移动；
5. 如果层级不合适，回到正文给标题换成更合适的标题样式。

这样，修改思路不必总是在几十页正文里寻找、剪切和粘贴，而可以先从结构层面判断“这一整节应该放到哪里”。

## 一个很实用的写作循环

不需要先把完整大纲一次想完。可以反复循环：

**想到 → 写下 → 归类 → 命名 → 看整体结构 → 调整顺序 → 发现缺口 → 继续写**

例如刚开始时，你甚至只需要写几个粗略的一级标题。想到新内容就先写进去；当某一节越来越长，再把它拆成二级、三级标题。写到中途发现顺序不对，就在导航窗格里重新排列。

这是一种“边写边想、边想边重构”的工作方式。

## 思想结构和最终文稿是同一份文档

这是使用 Word 做结构化写作的一个重要价值：**思考时建立的标题层级，就是最终文章或书稿的真实结构。**

你不需要为了进入正式写作阶段重新复制一遍大纲。标题可以继续变成目录、页眉、编号和交叉引用的基础；正文也一直留在同一份文档里。

因此，这套模板把能力按下面的顺序理解：

**思考 → 结构 → 写作 → 排版**

自动编号、目录、页码、题注、脚注和参考文献都很重要，但它们的作用是尽量减少技术细节对思考和写作的打断，而不是成为写作的中心。

## 不要把结构变成新的负担

结构是辅助，不是规则竞赛。

- 不需要一开始就设计完美大纲；
- 不需要为了“看起来完整”强行凑很多标题；
- 不是每一段都需要标题；
- 某些内容暂时不知道放哪里，可以先写，之后再整理；
- 标题层级应该服务于内容关系，而不是为了显示更多编号。

如果结构让你更难开始，就先写正文；等材料变多以后再回头整理。模板的目的始终是降低组织思路的摩擦。

## 第一次体验，可以只做三件事

1. 写下 3～5 个“标题 1”，每个标题代表一个你想讨论的大问题；
2. 在每个标题下面随便写几段内容，不要求完整；
3. 打开导航窗格，看一眼整体顺序，然后尝试拖动一个章节。

做完这三步，就已经在使用这套模板最核心的能力了。

如果你只是想马上开写，继续看 [`快速开始.md`](快速开始.md)。如果文稿已经很长，可以再看 [`进阶使用.md`](进阶使用.md)。
