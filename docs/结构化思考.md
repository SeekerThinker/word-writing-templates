# 结构化思考：这套模板为什么存在

这套模板最核心的初衷不是“把 Word 排得更漂亮”，而是**用结构化写作辅助思考**。

## 让思路变得可见

人在写长文章、报告、论文或书稿时，真正困难的往往不是打字，而是持续回答这些问题：

- 这一部分到底在讲什么？
- 它属于哪个更大的主题？
- 哪些内容应该并列，哪些应该从属于前一层？
- 哪里重复了，哪里缺了一块？
- 现在的顺序是否最清楚？

把内容放进“标题 1 / 标题 2 / 标题 3 / 标题 4”这样的层级里，本质上是在不断给想法**分组、命名、排序并建立关系**。

结构不会自动替你产生好观点，但它会把原本藏在连续文字里的关系显现出来。层级太深、主题重复、论点位置不合适、某一章内容失衡，都会更容易被发现。

## 导航窗格：把文稿变成可观察的结构

只要使用 Word 的标题样式，导航窗格就可以按标题显示全文结构。这样，一篇几十页甚至更长的文稿，不再只是连续页面，而会同时呈现为一棵层级结构。

这使写作过程中可以不断在两个尺度之间切换：

- **局部**：专心写当前这一段、这一节；
- **整体**：回到导航窗格检查全篇结构和当前位置。

在支持该操作的 Word 桌面版本中，还可以从导航窗格拖动标题来重新安排文档部分，并调整标题层级。不同平台或 Word 版本的具体界面可能略有差异，因此项目不会把某一种界面行为夸大成所有版本都完全一致。

## 不必先把大纲一次想完

结构化写作不要求“先把完整大纲想好，再开始正文”。更实用的方式往往是循环进行：

**想到 → 写下 → 归类 → 命名 → 看整体 → 调整顺序 → 发现缺口 → 继续写。**

因此，标题层级不是写作开始前的一次性准备，而可以贯穿整个思考过程。一个标题可以先只是临时想法，后面再改名、拆分、合并或移动。

## 思想结构和最终文稿是同一份文件

这套模板希望减少“思考”和“成稿”之间的转换成本。

你在标题层级里整理出来的结构，就是之后目录、导航、编号和正文组织所依赖的同一套结构。随着内容成熟，它可以直接成长为最终 Word 文稿，而不需要重新搬运一遍大纲和正文。

## 排版为什么仍然重要

自动编号、目录、页码、题注、脚注、参考文献等功能并不是项目的中心目的，它们的价值是**减少排版摩擦，把注意力尽量留给内容和思考**。

因此这个项目的优先顺序是：

**思考 → 结构 → 写作 → 排版。**

如果某个新功能会让普通用户先学习更多设置、增加选择负担，却不能明显帮助思考或写作，它通常不应该进入核心路径。

## 第一次就这样用：5 分钟结构化思考

不用先写完整大纲，也不用先学 Word 的复杂功能。打开“直接开始版”后，可以只做一次很短的练习：

1. **写下主题。** 把这次真正想弄清楚的事情写成文档标题。
2. **先写 3～5 个“标题 1”。** 暂时把它们当成几个大问题、大方向或主要部分，不要求一开始就完美。
3. **在需要拆分的地方加“标题 2”。** 一个标题下面如果其实包含几个不同问题，就把它们拆开；还需要继续拆时再用“标题 3 / 标题 4”。
4. **打开导航窗格，只看标题。** 暂时不要盯正文，看看这棵结构树是否已经能说明“我准备怎么把这件事讲清楚”。
5. **调整一次结构。** 如果顺序不自然，就改标题名称、改变层级；在支持拖动重排的 Word 桌面版本中，也可以直接从导航窗格移动文档部分。
6. **只选一个分支开始写正文。** 写一会儿后，再回到导航窗格看全局。结构可以随着思考继续变化。

这 5 分钟的目的不是做出完美目录，而是尽快把脑中的关系放到眼前。只要结构开始可见，就已经可以用它继续思考。

## 每次回看结构，只问这 5 个问题

当你觉得“越写越乱”时，不一定马上修改句子。先回到导航窗格，只看标题，问：

- **并列吗？** 同一级标题是不是在讨论同一层次的问题？
- **单一吗？** 一个标题是不是同时塞进了两件应该拆开的事情？
- **完整吗？** 有没有明显缺少的一块，导致论述中间跳了一步？
- **重复吗？** 两个地方是不是其实在说同一件事，只是换了名字？
- **顺序对吗？** 现在的次序是否最容易理解，还是应该先讲原因、背景、定义或结论中的某一项？

这些问题没有唯一答案。它们的作用是把“感觉有点乱”变成几个可以操作的结构问题。

## 一个简单的长期节奏

真正写长文时，可以反复使用同一个循环：

**写一点正文 → 看一次导航结构 → 改一个标题或位置 → 发现新问题 → 再写正文。**

不需要每写一段都调整结构，也不需要把导航窗格变成额外负担。它更像一个随时可以拉远视角的“全局窗口”：写作卡住时看结构，结构想清楚后再回到正文。

这套模板不会替你思考，但它希望让你的思考**更容易被看见、检查和重组**。
