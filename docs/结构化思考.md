# 结构化思考：这套模板为什么存在

这套模板最核心的初衷不是“把 Word 排得更漂亮”，而是**让思考的结构变得可见、可检查、可调整**。

它可以服务于很多不同场景：整理一个复杂问题、积累日常笔记、组织研究材料，也可以用来写报告、论文或书稿。是否最终形成文章，并不是使用这套模板的前提。

## 让思路变得可见

当一个问题越来越复杂、笔记越来越多，或者一篇长文逐渐展开时，真正困难的往往不是打字，而是持续回答这些问题：

- 这一部分到底在讲什么？
- 它属于哪个更大的主题？
- 哪些内容应该并列，哪些应该从属于前一层？
- 哪里重复了，哪里缺了一块？
- 现在的顺序是否最清楚？

把内容放进“标题 1 / 标题 2 / 标题 3 / 标题 4”这样的层级里，本质上是在不断给想法**分组、命名、排序并建立关系**。

结构不会自动替你产生好观点，但它会把原本藏在连续文字里的关系显现出来。层级太深、主题重复、位置不合适、某一部分明显失衡，都会更容易被发现。

## 导航窗格：把内容变成可观察的结构

只要使用 Word 的标题样式，导航窗格就可以按标题显示文档结构。这样，一份内容很多的文档不再只是连续页面，而会同时呈现为一棵层级结构。

这使你可以不断在两个尺度之间切换：

- **局部**：专心处理眼前的一条笔记、一段材料或一节正文；
- **整体**：回到导航窗格，看各部分之间的关系和当前位置。

在支持该操作的 Word 桌面版本中，还可以从导航窗格拖动标题来重新安排文档部分，并调整标题层级。不同平台或 Word 版本的具体界面可能略有差异，因此项目不会把某一种界面行为夸大成所有版本都完全一致。

## 不必先把结构一次想完

结构化思考不要求“先把完整大纲想好，再开始记录或写作”。更实用的方式往往是循环进行：

**想到 → 写下 → 归类 → 命名 → 看整体 → 调整顺序 → 发现缺口 → 继续记录或展开。**

因此，标题层级不是开始前的一次性准备，而可以贯穿整个思考过程。一个标题可以先只是临时想法，后面再改名、拆分、合并或移动。

这也是为什么它适合长期积累：今天记下的一条材料不需要马上知道最后会放在哪里。先让它进入一个大致合适的位置，等内容变多以后，再从整体上重新理解和调整。

## 整理与成稿可以共用同一份文件

这套模板希望减少“整理思路”和“正式写作”之间的转换成本，但**并不要求整理最终一定走向成稿**。

你可以一直把文档当作问题笔记、材料库或长期知识记录。标题层级和导航窗格本身就已经能承担结构化思考的工作。

如果后来确实需要把其中一部分发展成文章、报告或书稿，你已经整理出来的标题关系，也正是目录、导航、编号和正文组织可以继续使用的结构。这样不需要先在别的工具里做完大纲，再把内容重新搬进 Word。

换句话说：**成稿是这套结构能够继续走向的地方之一，而不是预设终点。**

## 排版为什么仍然重要

自动编号、目录、页码、题注、脚注、参考文献等功能并不是项目的中心目的，它们的价值是**减少排版摩擦，把注意力尽量留给内容和思考**。

因此这个项目的优先顺序是：

**思考 → 结构 → 记录 / 写作 → 排版。**

如果某个新功能会让普通用户先学习更多设置、增加选择负担，却不能明显帮助思考、记录或写作，它通常不应该进入核心路径。

## 第一次就这样用：5 分钟结构化思考

不用先写完整大纲，也不用先学 Word 的复杂功能。打开模板后，可以只做一次很短的练习：

1. **写下主题。** 把这次真正想弄清楚的事情写成文档标题。
2. **先写 3～5 个“标题 1”。** 暂时把它们当成几个大问题、大方向或主要部分，不要求一开始就完美。
3. **在需要拆分的地方加“标题 2”。** 一个标题下面如果其实包含几个不同问题，就把它们拆开；还需要继续拆时再用“标题 3 / 标题 4”。
4. **打开导航窗格，只看标题。** 暂时不要盯正文，看看这棵结构树是否已经能说明“这些内容之间是什么关系”。
5. **调整一次结构。** 如果顺序不自然，就改标题名称、改变层级；在支持拖动重排的 Word 桌面版本中，也可以直接从导航窗格移动文档部分。
6. **选一个分支继续记录或展开。** 过一会儿，再回到导航窗格看全局。结构可以随着思考继续变化。

这 5 分钟的目的不是做出完美目录，而是尽快把脑中的关系放到眼前。只要结构开始可见，就已经可以用它继续思考。

## 每次回看结构，只问这 5 个问题

当你觉得内容“越来越乱”时，不一定马上修改句子。先回到导航窗格，只看标题，问：

- **并列吗？** 同一级标题是不是在讨论同一层次的问题？
- **单一吗？** 一个标题是不是同时塞进了两件应该拆开的事情？
- **完整吗？** 有没有明显缺少的一块，导致关系中间跳了一步？
- **重复吗？** 两个地方是不是其实在说同一件事，只是换了名字？
- **顺序对吗？** 现在的次序是否最容易理解，还是应该重新排列？

这些问题没有唯一答案。它们的作用是把“感觉有点乱”变成几个可以操作的结构问题。

## 一个可以长期使用的节奏

无论是在积累笔记，还是已经进入正式写作，都可以反复使用同一个循环：

**记录一点内容 → 看一次导航结构 → 改一个标题或位置 → 发现新问题 → 再继续。**

不需要每写一段都调整结构，也不需要把导航窗格变成额外负担。它更像一个随时可以拉远视角的“全局窗口”：局部卡住时看整体，整体想清楚后再回到当前内容。

这套模板不会替你思考，但它希望让你的思考**更容易被看见、检查和重组**。
