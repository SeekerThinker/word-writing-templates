# 项目持久决定

本页只记录会约束未来维护的**用户已经明确采纳的方向**和少量尚未确定的事项；不复制聊天、不替代 `STABILITY.md`、README、源码、Git 历史或 PR diff。事实与实现状态仍以仓库当前版本及相应 PR / CI 为准。新增决定应说明变化，并同步到受影响的文档和代码。

## 已确认的方向

- **项目目的**：把 Word 作为辅助思考、记录与写作的环境；优先顺序是「思考 → 结构 → 记录 / 写作 → 排版」。整理思路、积累笔记本身就是完整用途，成稿是可选延伸。详见 [README](../README.md)、[STABILITY](../STABILITY.md)。
- **稳定模板**：v4 六种编号 × Windows/macOS，共 12 个公共 `.dotx`；一套编号只对应一个用户模板，既有公共路径、下载文件名和无宏体验保持稳定。详见 [STABILITY](../STABILITY.md)。
- **双起点**：用户可以直接在 Word 中使用 `.dotx`，也可以先用网页编辑器整理和写作，导出 `.docx` 后在 Word 中继续。网页不承诺无损导入任意 Word 文档。相关实现见 [PR #33](https://github.com/SeekerThinker/word-writing-templates/pull/33)。
- **全文与结构并行**：网页默认可编辑整篇连续文档；左侧标题树与正文相互定位；只读页面预览和专注当前节是可选视图。页面预览不冒充精确 Word 分页。见 [PR #34](https://github.com/SeekerThinker/word-writing-templates/pull/34)。
- **跨平台一致性**：网页和 Word 的标题、正文、表格、引用、脚注样式命令使用相同的 Windows/macOS 快捷键；网页专有的结构操作另列。表格和脚注是独立数据模型，导出为 Word 原生对象。见 [PR #35](https://github.com/SeekerThinker/word-writing-templates/pull/35)、[PR #36](https://github.com/SeekerThinker/word-writing-templates/pull/36)。
- **双语但不混淆语言**：网站和使用说明提供中文/英文、根据浏览器首选语言选择首次界面、允许手动切换；文档语言与编号方案独立，英文界面中的中文传统指**编号方式**而非 Traditional Chinese 字符。见 [PR #32](https://github.com/SeekerThinker/word-writing-templates/pull/32)、[PR #33](https://github.com/SeekerThinker/word-writing-templates/pull/33)。
- **文字气质**：页面沿用主页「标题层级、全局视野、局部与整体来回、结构可调整」的自然、克制表达；工具按钮保持清楚实用。见 [PR #37](https://github.com/SeekerThinker/word-writing-templates/pull/37)。
- **隐私与保存**：网页草稿默认本地保存；应提供 JSON 备份恢复和 Word 导出，并诚实说明清除浏览器数据、跨设备与离线能力的限制。详见 [在线编辑器说明](在线编辑器.md)。

## 待确定、不得当成已上线能力

- **自愿支持 / 打赏**：用户希望国内外都能方便支付，但实际收款主体、合规可用的支付渠道和真实收款链接尚未确定。此前准备的支持页分支不能被描述为已经上线的支付能力；不得生成虚构付款按钮、账号或二维码。支付接入须由项目所有者决定并提供有效渠道。
- **AI 辅助写作**：本项目目前没有承诺 AI 代写、云同步或研究协议合规。参考 [HARC](https://github.com/ChongLiuPhil/Human-AI-Research-Collaboration-Protocol) 仅用于改善维护者的项目交接和决策可追溯性，不自动引入复杂审批流程。

## 更新约定

用户明确修改方向时，先核对其与稳定承诺的关系，更新本页及受影响的 README、代码、双语页面和检查；只属 AI 建议的内容留在 PR 讨论或待决定项，不擅自提升为已确认。已做过的测试与尚未做过的真实 Word / 浏览器操作应分别陈述。
