# macOS / MacBook 使用说明

推荐 Microsoft Word for Mac。

## 快捷键

- 一级标题：`⌘ + ⌥ + 1`
- 二级标题：`⌘ + ⌥ + 2`
- 三级标题：`⌘ + ⌥ + 3`
- 四级标题：`⌘ + ⌥ + 4`
- 正文：`⌘ + ⌥ + Z`
- 表格文字：`⌘ + ⌥ + B`
- 引用：`⌘ + ⌥ + Q`
- 插入脚注：`⌘ + ⌥ + F`

macOS 版模板优先使用 macOS 自带的中文字体（如 PingFang SC、Songti SC、Kaiti SC），减少缺字和字体替换。

如果某个组合键被 macOS、输入法或 Word 插件占用，仍可直接从 Word 的“样式”区域选择对应标题和正文样式。
