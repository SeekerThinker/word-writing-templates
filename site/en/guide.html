A Word guide specifically for these templates

Start with the Navigation Pane.
Use the document as a thinking and writing tool.

This is not a general Word manual. It focuses on the features that matter for this workflow: heading levels, the Navigation Pane, keyboard shortcuts, structural rearrangement, and the table of contents when you need a finished document.

Step one

Double-click the `.dotx` and start from a new document

After downloading a template, simply double-click it. Word creates a new document based on the template. You work in the new document; the original `.dotx` stays unchanged.

You do not need to “install” the template

The simplest workflow is to keep the `.dotx` in any convenient folder and double-click it whenever you need a new document. The template's styles, numbering, and shortcuts apply to the template and documents created from it; they do not overwrite Word's global template or your existing global settings.

If you later want it to appear in Word's template gallery, you can choose to place it in a personal template location. That is optional.

Step two

Open the Navigation Pane and keep the whole structure beside the text

The Navigation Pane is central to this method. In Word for Windows desktop, open View → Navigation Pane. You can also press Ctrl + F. On Mac, you can also open the Navigation Pane from View, although layout and some behaviors differ by Word version.

Use the headings view

Once the pane is open, show the document's headings. Any paragraph that uses Heading 1, Heading 2, Heading 3, and so on appears there in hierarchy.

Think of the pane on the left as the global view and the document body on the right as the local view. Work on the immediate passage on the right; step back to the left when you need to judge the whole.

Step three

Do not merely make text look like a heading—assign a real heading level

Select a line, then choose Heading 1, Heading 2, Heading 3, or Heading 4 from Home → Styles. This changes more than appearance: it tells Word how that part relates to the rest of the document.

Use levels for parallel and nested relationships

Heading 1 can hold major topics or chapters. Heading 2 is a major part within that topic. Heading 3 and 4 continue the subdivision. Ordinary paragraphs remain body text.

The templates already configure typography, spacing, and multilevel numbering. Your main job is to decide what role each passage plays in the hierarchy.

Step four

If the order is wrong, reorganize from the structural view

In the Headings view of the Navigation Pane in Word for Windows desktop, you can drag a heading to a new position. Word moves that heading together with the body text and lower-level headings that belong to the section.

You are moving a whole section, not just the heading text

If you move “What the real tension is” above “Where the problem comes from,” the subsection “Evidence and examples” and the related body text move with it. This is one of the most useful Word behaviors for structural thinking.

Word for Windows also lets you use heading context commands for some hierarchy operations. Protected regions can limit what may be dragged or moved.

Rename

If a heading is vague, rename it. Naming the section more clearly often changes how you understand its material.

Split

If one heading contains several different questions, split them into parallel headings.

Merge

If two sections are really about the same thing, merge them to remove repetition.

Promote or demote

If a section is more central or more subordinate than you first thought, change its heading level to express that relationship.

A useful habit: keep ordinary writing as body text. When a passage deserves to be visible in the overall structure, name it as a heading and choose its level. Do not assign heading styles merely for visual emphasis, or the Navigation Pane will become noisy.

Step six

When you need a finished document, let the structure keep working

Heading levels are useful before formal writing, but they also power Word's document features. An automatic table of contents is generated from headings, so a structure built while thinking can continue directly into a paper, report, or book.

Insert an automatic table of contents

Place the cursor where you want the table of contents, then choose References → Table of Contents and select an automatic table. If headings, order, or page numbers later change, update the table.

Page numbers, captions, footnotes, and references can be added when they become useful. You do not need to handle all of them while you are still organizing ideas.

Troubleshooting

If a heading does not appear in the pane

You only made the text bold or larger

The Navigation Pane responds to heading styles, not text that merely looks like a heading. Apply Heading 1, 2, 3, or 4.

The heading is inside a table or text box

Microsoft notes that the Navigation Pane does not show headings located in tables, text boxes, headers, or footers. Keep core structural headings in the main document body.

An item is missing from the table of contents

Check whether the line actually uses a heading style, then update the automatic table of contents.

A section will not drag

Navigation Pane behavior varies by platform and version, and protected document regions can restrict movement. If necessary, move the section from the document body instead.
