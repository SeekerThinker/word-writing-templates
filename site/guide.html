专门围绕这套模板的 Word 使用说明

从打开导航窗格开始，
把文档用成思维与写作工具。

这里不讲 Word 的所有功能，只讲与这套模板最相关的操作：标题层级、导航窗格、快捷键、结构重排，以及需要成稿时的目录等功能。

第一步

双击 `.dotx`，从一份新文档开始

下载模板后直接双击。Word 会基于模板创建一份新的文档，你在新文档里记录和写作，原来的 `.dotx` 模板文件保持不变。

不用“安装”模板

最简单的用法就是把 `.dotx` 留在你习惯的文件夹里，需要时双击。模板中的样式、编号和快捷键跟随这个模板及其创建的文档使用，不会去改动 Word 的全局模板或你原来的全局设置。

如果以后想长期使用，再决定是否把它放进自己的模板目录；普通用户不需要先做这一步。

第二步

打开导航窗格，把全文结构放到左边

导航窗格是这套方法的关键。Windows 桌面版可以在“视图（View）”中勾选“导航窗格（Navigation Pane）”；也可以按 Ctrl + F 打开。Mac 版同样可以从“视图（View）”中打开导航窗格，但具体布局和部分行为会因版本不同而略有差异。

进入“标题”视图

打开窗格后，切换到显示标题或文档结构的视图。只要正文里的段落应用了“标题 1 / 标题 2 / 标题 3 ……”样式，它们就会按层级出现在这里。

以后你可以把左边理解成“全局”，把右边正文理解成“局部”。写具体内容时看右边；判断整体关系时看左边。

注意：微软官方明确说明，导航窗格在 Windows、Mac 和网页版 Word 中的行为并不完全相同。本教程把 Windows 桌面版作为拖动重排的主要示例；Mac 上以你当前 Word 版本实际提供的功能为准。

第三步

不要手动“做大字体”，而是给内容真正的标题层级

选中一行文字，在“开始（Home）→ 样式（Styles）”中选择“标题 1、标题 2、标题 3、标题 4”。这不仅改变外观，也是在告诉 Word：这几段内容之间是什么关系。

用层级表达并列与从属

标题 1 可以放大的主题或章节；标题 2 是主题下的重要部分；标题 3、4 再继续细分。正文仍然使用正文样式，不要为了“看起来像标题”而只手动加粗、放大。

本模板已经把这些样式的字体、间距和多级编号配好，你主要负责判断“这一段是什么层级”。

第四步

顺序不对，就从结构视图里重排

在 Windows 桌面版 Word 的导航窗格“标题”视图里，可以直接拖动标题到新的位置。Word 会把这个标题以及它下面属于这一节的正文和下级标题一起移动。

移动的是“一整节”，不是一个标题文字

例如把“真正的矛盾是什么”拖到“问题从哪里来”之前，它下面的“证据与例子”和相关正文会一起移动。这正是导航窗格对结构化思考最有用的地方。

Windows 版还可以在导航窗格中右键标题调整标题级别或新增标题。遇到受保护的文档区域时，拖动范围可能受到限制。

改名

标题说不清楚，就直接改标题。重新命名往往也是重新理解这一组内容。

拆分

一个标题下面塞了太多不同问题，就拆成两个并列标题。

合并

两个部分其实在讲同一件事，就合并标题和正文，减少重复。

升降层级

如果一部分其实更重要或更次要，就调整它的标题级别，重新表达从属关系。

一个简单习惯：写正文时保持正文样式；发现“这一段需要被整体看见”时，再把它命名成标题并选择层级。不要为了排版效果随意把普通段落设成标题，否则导航窗格会变得嘈杂。

第六步

需要成稿时，让前面的结构继续发挥作用

标题层级不仅服务于思考。Word 的自动目录本身就是根据标题生成的，所以当结构已经整理清楚，进入正式写作时不必重新搭一遍目录体系。

插入自动目录

把光标放到需要目录的位置，在“引用（References）→ 目录（Table of Contents）”里选择自动目录。以后标题文字、顺序或层级发生变化，可以更新目录。

页码、题注、脚注、参考文献等功能可以按需要逐步使用；不必在刚开始整理思路时一次全部处理。

常见问题

如果左边没有出现你想要的标题

只加粗、放大了文字

导航窗格识别的是标题样式，不是视觉上“像标题”。选中文字后应用“标题 1 / 2 / 3 / 4”。

标题放在表格或文本框里

Windows 官方说明中，导航窗格不会显示位于表格、文本框、页眉或页脚里的标题。核心结构标题尽量放在正文中。

目录少了一项

先检查那一行是否真正使用了标题样式，再更新自动目录。目录是根据标题结构生成的。

拖不动某一节

不同平台和版本的导航窗格行为可能不同；受保护区域也会限制拖动。此时可以回到正文中剪切、粘贴整节内容。
